==================================================================
                   SECTION 5: METRIC DEFINITIONS
==================================================================

ERROR METRICS:
- MAPE: Mean Absolute Percentage Error vs DP optimal cost.
- Median Err: Median of per-chain percentage errors.
- P95 Err: 95th percentile error (worst 5% of predictions).
- Max Err: Worst single prediction across all test chains.
- MAE: Mean Absolute Error in raw cost units.
- RMSE: Root Mean Square Error in raw cost units.

REGRESSION QUALITY:
- R2 (raw): Coefficient of determination on raw cost values.
- R2 (log1p): R2 on log1p-transformed costs (better for 
  comparing across scales).
- Pearson r: Linear correlation coefficient.
- Spearman rho: Rank correlation coefficient.

VALIDITY:
- Valid Rate: % predictions where predicted cost >= DP optimal.
  DP finds the absolute minimum. Predicting below it means the 
  model hallucinated an impossible parenthesization.
- Within X%: % predictions with error less than X%.

STRUCTURAL (Neural Models Only):
- Exact Match: % where predicted splits = DP optimal splits.
- F1-Score (<1%): F1 treating "within 1% error" as positive class.
- Precision (<1%): % of all predictions that are within 1%.
- Recall (<1%): % of valid chains correctly predicted within 1%.
- F1-Strict (<0.1%): F1 with a tighter 0.1% threshold.

SIGNIFICANCE:
- Wilcoxon Signed-Rank: Non-parametric test for paired differences.
- p-value: Probability of observing results under null hypothesis.
- Cohen's d: Effect size (small: 0.2, medium: 0.5, large: 0.8).
